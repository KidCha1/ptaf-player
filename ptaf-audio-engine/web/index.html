PTAF Format Tour

  • * (Sticky Note): Ignored comments for track details or metadata.
  • ^ (File Bounds): Audio instructions are strictly executed between opening and closing carats.
  • tempo = X: Adjusts speed in beats per minute.
  • note = C3: Specifies octave alongside the note (defaults to octave 4).
  • note = Cmaj / note = Amin: Plays full major and minor triads automatically.
  • note = C4E4G4: Plays stacked polyphonic notes simultaneously across any octave.
  • pitch = X: Direct oscillator pitch in Hertz (e.g., 440 or 523.25).
